# Interactive Web Elements ⚡

A modern interactive frontend project built using **HTML, CSS, and Vanilla JavaScript** showcasing advanced DOM manipulation, event handling, animations, and dynamic UI interactions.

## 🚀 Live Features

- 🌙 Dark Mode Toggle
- 🔢 Interactive Counter App
- ✍️ Live Character & Word Counter
- ✅ Dynamic Todo List with localStorage
- ❓ FAQ Accordion
- 🔔 Toast Notification System
- 🖼️ Interactive Image Gallery
- ⌨️ Keyboard Event Detector
- ✨ Scroll Reveal Animations
- 🎨 Glassmorphism UI Design
- 🌈 Animated Gradient Backgrounds
- 📱 Fully Responsive Layout
